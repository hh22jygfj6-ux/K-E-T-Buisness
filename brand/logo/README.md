# Logo – Original-Datei

Hier bitte die **Original-Logodatei** ablegen (bevorzugt SVG oder PNG mit hoher Auflösung, zusätzlich ggf. PDF/EPS).

Beschreibung: Mandala mit Schmetterling, weiß auf blau.

Das Logo darf niemals verändert, neu interpretiert oder durch ein ähnliches Symbol ersetzt werden.
Solange hier keine Datei liegt, wird kein Logo erzeugt – es wird nachgefragt.
